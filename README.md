# Takhti IT School (demo)

An IT courses site with free and paid courses, lesson progress, a quiz and a printable certificate. Nothing is charged.

**Live:** https://takhti-it-school-demo.pages.dev

A demo website. The business, prices and reviews are made up and nothing is charged or sent. Photos are from Unsplash under the Unsplash License and credited on the site.

## Built with

- [Astro](https://astro.build) static site, plain CSS, no runtime JavaScript framework
- Deployed on Cloudflare Pages

## Run it

```bash
npm install
npm run dev      # local dev server
npm run build    # static build into dist/
```
